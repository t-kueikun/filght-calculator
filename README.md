# AeroLab 使い方ガイド

AeroLabは、3Dプリンターで作る小型航空機について、翼の形・重さ・重心・投げ方を変えたときの飛び方を比較するシミュレーターです。機体の形を見ながら、飛行経路、速さ、揚力や抵抗、機首の動きを確認できます。

最初はGL-01グライダーの設定をそのまま計算し、重心や翼幅などを1つずつ変えて比べるのがおすすめです。物理の知識がなくても、下の手順で始められます。

対象はアプリv0.3.0、計算モデル `3dof-naca-1.1` です。実機の飛距離を確定するものではなく、設計変更の傾向を学ぶための近似モデルです。

## 2 シミュレーターを開く

### 公開済みのURLで使う場合

PCでもスマホでも、公開されたシミュレーターのURLをブラウザで開きます。アプリのインストールは不要です。Vercelなどに画面とPython APIが公開されていれば、公開した人のPCを起動し続ける必要はありません。

初回に結果が出るまで少し待ち、プリセットの機体とグラフが表示されることを確認してください。

### 自分のPCで動かす場合

1. Python 3.10以上をインストールします。Vercel向けの構成ではPython 3.12を指定しています。
2. アプリ本体のZIPを完全に展開するか、ソースコードを取得します。
3. `launch.py`、`pyproject.toml`、`aeroflight`、`frontend` があるフォルダを開きます。
4. Windowsは `start.bat`、macOSは `start.command` を実行します。
5. 起動したターミナルを開いたまま、ブラウザで次を開きます。

```text
http://127.0.0.1:8000
```

初回は必要なPythonライブラリをインストールするため、インターネット接続が必要です。終了するときはターミナルで `Ctrl+C` を押します。

起動ファイルを直接開けない場合は、プロジェクトのフォルダで次を実行してください。

Windows：

```sh
python launch.py
```

macOS・Linux：

```sh
python3 launch.py
```

`python` コマンドが見つからないWindows環境では、`py -3 launch.py` も使えます。

### ソースコードにビルド済みの画面がない場合

`frontend/dist/index.html` がない場合は、先に画面をビルドします。Node.jsとnpmが必要です。Node.js 22 LTS以降を目安にしてください。

プロジェクト直下のターミナルから実行します。

```sh
cd frontend
npm ci
npm run build
cd ..
```

その後、`launch.py` で起動します。ビルド済み画面を含む配布版を使うだけなら、Node.jsは不要です。

## 3 最初の飛行を計算する

1. プリセットから **GL-01 手投げグライダー** を選びます。モーター付き機を試したい場合は **RC-02 プロペラ機** を選びます。どちらも説明用の架空の機体です。
2. 最初は値を変えずに結果を確認します。自動計算がオンなら計算されます。オフなら **計算実行** を押します。
3. 機体の形、飛行経路、解析結果、画面下部の注意表示を確認します。
4. **設計を保存** を押し、比較の基準として残します。
5. 入力を1つだけ変え、もう一度計算します。
6. 保存した案とグラフを重ね、違いを確認します。

最初に試しやすい入力は、総重量、重心位置、翼幅、初速度です。複数の値を一度に変えると原因を追いにくいため、慣れるまでは1項目ずつ比較してください。

## 4 画面の操作

| 場所 | できること |
| --- | --- |
| 設計パネル | 重量、重心、主翼、翼型、尾翼、推進、飛行条件、計算設定を変更します。 |
| 機体プレビュー | 3D・上面・側面で形を確認します。3Dはドラッグで回転できます。 |
| 飛行経路 | どこまで、どの高さを飛ぶか確認します。再生ボタンで飛行中の位置と姿勢を追えます。 |
| 解析結果 | 距離、時間、最高高度、対気速度、静安定余裕などを確認します。 |
| 詳細グラフ | 速度、空気力、姿勢・迎角、ピッチ角速度を切り替えます。 |
| 保存済みの設計 | 保存した条件の読込、削除、グラフの重ね合わせを行います。 |
| 学習ガイド | 数値の意味と、計算済みの3条件の比較を読みます。 |

スライダーの変更は即座に設定へ反映されます。数値を直接入力した場合は、Enterを押すか入力欄の外をクリックすると反映されます。空欄や範囲外の値は元の値に戻ります。

自動計算は、操作が止まってから約0.35秒後に再実行します。設定変更後に結果がまだ更新されていない間はグラフが薄くなり、保存やCSV出力が使えません。計算が終わるまで待つか、手動なら **計算実行** を押してください。

### 再生とグラフ

- 再生・一時停止と、0.5倍・1倍・2倍・4倍の速度を使えます。
- 時刻スライダーやグラフの点を選ぶと、その時刻の位置・姿勢・力を確認できます。
- グラフはドラッグで拡大し、ダブルクリックで表示を戻せます。ツールバーから画像保存なども行えます。
- 凡例を選ぶと、その線の表示を切り替えられます。

飛行経路の横軸と縦軸は表示上の縮尺が異なるため、画面の線の傾きをそのまま実際の上昇角と考えないでください。

## 5 入力する数値の基本

| 項目 | 意味 | まず知っておくこと |
| --- | --- | --- |
| 総重量 | 機体・電池・モーター・搭載物を含む質量 | 同じ翼なら、重いほど重さを支えるのに必要な速度が上がります。 |
| CG 重心 | 機体の重さの中心 | % MACが大きいほど後ろ重心です。 |
| MAC | 翼の前後長さを代表する長さ | このモデルのCG30% MACは、主翼前縁からMACの30%だけ後方です。 |
| テーパー比 | 翼端の前後長さ÷翼根の前後長さ | 1は長方形翼です。小さくすると翼端が細くなり、面積なども変わります。 |
| キャンバー | 翼型の反り | NACAモードでは揚力と機首を回す作用に反映されます。 |
| ピッチ角 | 機首が向いている角度 | 投げる速度の向きである投射角とは別です。 |
| 迎角 | 翼と、その場所に来る空気の向きの差 | 揚力や失速への近づき方に関係します。 |
| Iyy | 機首を上下に回すときの回りにくさ | 大きいほど同じモーメントで回転速度が変わりにくくなります。 |

画面にはg、mm、cm²などで表示する欄があります。表示されている単位に合わせて入力してください。内部の計算とCSVでは、主にkg、m、秒、Nを使います。出力の角度は度、角速度は度/秒です。

### 重さを入力する2つの方法

**直接入力**では、総質量、CG、Iyyをそれぞれ指定します。重さだけを変えても重心やIyyは自動では変わりません。

**部品から算出**では、部品ごとの重さ、前後・上下の配置、部品自身のIyyから機体全体の値を求めます。電池や重りを動かす比較に向いています。部品の前後位置xは主翼前縁から後方が正、上下位置zは下方が正です。

## 6 翼型と形状を編集する

主翼の翼幅、翼根翼弦長、テーパー比などを変えると、表示される形状が変わります。**翼型を編集** から断面の設定へ移動できます。

NACAモードでは、0012・2412・4412・2415などのプリセットや、反り・反りの位置・厚みの指定を使います。NACA 2412は反り2%、反り位置40%、厚み12%を表します。

**見た目の変化が、すべて空力計算へ反映されるわけではありません。**

- 反りと反り位置は、NACAモードで零揚力角とCmを通じて飛行計算に反映されます。
- 翼厚は形状表示に使いますが、厚みに応じた抵抗・CLmax・重量・Iyyの自動変更はありません。
- 胴体は模式表示です。尖らせた形から抵抗を自動算出せず、胴体の抵抗はCdAという入力値で扱います。
- 寸法を変えても質量やIyyは自動推定しません。必要に応じて別に更新します。

**DAT** は翼型断面の座標データを書き出します。機体全体のSTLや3Dプリント用CADデータではありません。翼型を係数の手入力モードで扱う場合は、実際の断面形状が未指定のためDATは使えません。

## 7 結果を読む

### 最初に終了理由を確認する

| 終了理由 | 距離の読み方 |
| --- | --- |
| 接地 | モデル上で地面へ到達するまでの水平距離です。 |
| 時間上限 | 設定時間までの水平変位です。まだ飛んでいる可能性があります。 |
| 有効範囲外 | 計算を打ち切った時点の水平変位です。着地までの予測ではありません。 |

距離だけを見る前に、3条件を同じ終了理由で比較できているか確認してください。特にプロペラ機では、計算時間を使い切っても飛び続けている場合があります。

### 速さと力

**対地速度**は地面に対する速さ、**対気速度**は空気に対する速さです。翼の揚力や抵抗には対気速度を使います。初速度の入力は対地速度で、風は追い風が正、向かい風が負です。

空気力のグラフでは、主翼揚力、尾翼揚力、抗力、推力、重力を見比べます。尾翼揚力は下向きになってマイナスで表示される場合もあります。姿勢が動くため、初めの揚力と重さだけで飛行全体の良し悪しは決められません。

**参考失速速度**は、主翼が指定された最大の揚力係数を使って機体の重さを支えるための目安です。表示値を下回った瞬間に実機と同じ失速が起きる仕組みではありません。

### CGと中立点と静安定余裕

中立点は、小さな迎角変化に対する機首の戻り作用が線形近似でゼロになる重心位置の目安です。静安定余裕は、CGが中立点よりどれだけ前にあるかをMACに対する割合で示します。

中立点42.8% MAC、CG30% MACなら、静安定余裕は12.8% MACです。正の値でも、一定姿勢で釣り合うことや、揺れが収まることまでは保証しません。CGと中立点を一致させても、最も遠くへ飛ぶとは限りません。

## 8 保存と比較とファイル出力

| 操作 | 用途 |
| --- | --- |
| 設計を保存 | 設定と結果を現在のブラウザに保存します。最大5案です。 |
| 保存案のチェックボックス | 保存した案の軌道や速度・姿勢の線を重ねて比較します。 |
| 読込 | 保存案の条件に戻し、再計算します。 |
| JSON | 設計条件をファイルに書き出します。別の端末へ移す場合にも使います。 |
| 読み込み | AeroLab形式のJSONから条件を読み込み、検証して再計算します。 |
| CSV | 現在の計算結果の時系列を、表計算ソフトなどで使える形に出力します。 |
| DAT | NACAモードで翼型断面の座標を出力します。 |

ブラウザ内の保存先は、同じブラウザ・同じURLの領域です。スマホとPC、別のブラウザ、異なる公開URLの間では自動同期しません。ブラウザの保存データを消すと保存案も消えるため、残したい条件はJSONでも保管してください。

JSONは現在の条件と、有効な計算結果がある場合はその結果を含みます。未計算の条件では結果は空です。読み込み時は保存結果をそのまま信用して表示せず、条件から再計算します。

### 比較の例

1. GL-01の初期状態を計算し、機体名を「基準」にして保存します。
2. 重心位置だけを30%から35% MACへ変更します。
3. 機体名を「後ろ重心」にして計算し、保存します。
4. 両方の保存案にチェックを入れます。
5. 静安定余裕と終了理由を確認し、飛行経路とピッチ角を見比べます。
6. 次の実験では基準案を読込み、変更する値を替えます。

## 9 教材を使う

ブラウザ版の右上にある **学習ガイド** から、`/learn.html` を開けます。44項目を選び、小さい値・基準・大きい値の3条件を切り替えて比較します。合計132条件は実際のエンジンで事前計算したもので、その場で自由な値を再計算する機能ではありません。

Markdown版の [learning-guide.md](learning-guide.md) には、同じ44項目の説明と3条件ずつの比較結果を表で収録しています。スライダーや3D表示の操作は含みません。資料だけを共有したい場合はこちらを使ってください。

アプリ本体にビルド済み教材がある場合は、`frontend/dist/learn.html` を直接ブラウザで開いて閲覧することもできます。この教材だけなら、Pythonサーバーを起動せずに計算済みの例を見られます。

## 10 スマホで開く方法

公開済みのVercelなどのURLをスマホで開く方法が手軽です。

`localhost` と `127.0.0.1` は、開いている端末自身を指します。PCの `localhost:8000` をスマホで入力しても、PCのアプリにはつながりません。クラウドCodex上の `localhost` も、自分のPCとは別です。

同じWi-Fi内のPCから配信する場合は、通常の起動を停止し、Python環境と画面のビルドを用意したうえで、次のように外部から接続できる起動方法を使います。

```sh
python -m uvicorn aeroflight.api:app --host 0.0.0.0 --port 8000
```

自動起動で作った仮想環境を使う場合は、macOS・Linuxでは `./.venv/bin/python`、Windowsでは `.venv\Scripts\python.exe` を上の `python` の代わりに使います。

その後、スマホから `http://PCのLAN内IPアドレス:8000` を開きます。PCのファイアウォールが接続を許可している必要があります。この方法はPCを起動している間だけ利用できます。

## 11 Vercelへ公開する場合

### 公開する範囲

**画面のある `frontend` だけでなく、Pythonの計算部分を含むプロジェクト全体を公開します。**

公開用の構成では、プロジェクト直下に `index.py`、`vercel.json`、`pyproject.toml`、`scripts/build_vercel.py` があり、その下に `aeroflight` と `frontend` が必要です。資料3点だけでは公開できません。

### 設定と公開

1. アプリのコードをGitHubへ置き、Vercelからリポジトリを取り込みます。
2. 複数アプリの選択画面が出た場合は、**app（FastAPI）** の **Import single project** を選びます。
3. Root Directoryを、`aeroflight` や `pyproject.toml` がある階層にします。リポジトリ直下なら空欄または `./` です。
4. Framework Presetは **FastAPI**、Build Commandは `python scripts/build_vercel.py`、Output DirectoryのOverrideはオフにします。
5. 保存してデプロイします。設定変更後は再デプロイが必要です。
6. 公開URLの末尾に `/api/health` を付けて開き、`"status":"ok"` を含む応答が出ることを確認します。
7. 通常の公開URLを開き、プリセットが読み込まれ、計算とグラフ表示が動くことを確認します。

公開用ビルドは画面の依存関係をインストールして画面を作り、ソース配布ZIPを生成します。Pythonの計算部分もVercel側で実行します。クラウド上の起動と計算は、実際のデプロイで確認してください。

### 説明書を誰でも読めるようにする

`README.md`、`calculation-method.md`、`learning-guide.md` を同じ場所に置き、GitHubの公開リポジトリへアップロードします。GitHubではREADMEが案内として表示され、残り2つへリンクできます。

GitHubが非公開のままなら、アクセス権のない人は読めません。また、GitHubへ置いたMarkdownが自動でVercelのWebページとして公開されるわけではありません。

## 12 困ったとき

| 症状 | 確認すること |
| --- | --- |
| `localhost:8000` が開かない | 自分のPCでアプリを起動しているか、ターミナルにエラーがないか確認します。クラウド側や別端末のlocalhostとは接続先が異なります。 |
| 8000番ポートが使用中 | 以前のAeroLabを起動しているターミナルでCtrl+Cを押して停止してから、起動し直します。 |
| `UIが未ビルドです` と出る | `frontend` 内で `npm ci` と `npm run build` を実行してから起動します。 |
| 画面は出るが `/api/presets` が404 | Python APIが配信されていない可能性があります。Vercelでfrontendだけを取り込んでいないか、Root DirectoryとFastAPIの設定を確認します。 |
| `FASTAPI_ENTRYPOINT_NOT_FOUND` | 起動先をVercelに指定します。下の設定例を参照してください。 |
| 保存やCSVのボタンが押せない | 条件変更後に計算が済んでいるか確認します。手動計算なら計算実行を押します。 |
| 設計を保存できない | 保存は最大5案です。不要な案を削除します。ブラウザの容量不足の場合はJSONで書き出して保管します。 |
| JSONを読み込めない | AeroLabから書き出した形式か、15MB以下か、値が入力範囲内か確認します。 |
| 厚みを変えても飛び方が変わらない | 現モデルでは厚みを空力計算へ反映しません。形状表示のみ変化します。 |
| スマホに保存案がない | 保存は端末間で同期しません。PCからJSONを書き出し、スマホで読み込みます。 |
| 距離が極端、計算が止まる | 終了理由と警告を確認し、プリセットへ戻してから1つずつ変更します。 |

FastAPIの起動先が自動検出されない構成では、プロジェクト直下の `pyproject.toml` に次を設定し、保存して再デプロイします。すでに `[tool.vercel]` がある場合は、その中の `entrypoint` を変更し、同じセクションを二重に追加しないでください。

```toml
[tool.vercel]
entrypoint = "aeroflight.api:app"
```

## 13 計算結果を使うときの注意

計算しているのは、前後・上下の移動と、機首を上げ下げする回転です。横方向の旋回やロール・ヨーは対象外です。

翼の反りによる効果や主翼・尾翼・胴体の抵抗は近似しますが、実機との誤差が何%かは検証されていません。失速後の流れ、低速での剥離、積層痕、翼のたわみや破損、地面効果、突風、プロペラ後流、電池消耗などは十分に再現しません。

数値計算の刻みを細かくしても、こうした空力モデルの限界はなくなりません。実機の試験結果と照らし合わせながら、設計変更の傾向を比較するために使ってください。

詳しい仕組みと式は [calculation-method.md](calculation-method.md)、数値を動かす練習は [learning-guide.md](learning-guide.md) を参照してください。
