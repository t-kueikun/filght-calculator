# AeroLab — 3Dプリント航空機 フライトシミュレーター

仕様書 Phase 1 に機体形状プレビューとNACA翼型連動を加えた v0.2 のローカルWebアプリです。Pythonの独立した縦方向3自由度エンジンを、FastAPIとReact / TypeScript / Vite / Plotlyの日本語UIから操作します。グラフはすべてエンジンの計算結果を使用します。

## 起動

### お使いのPCで開く

クラウド環境の `localhost:8000` は、お使いのPCの `localhost:8000` とは別です。PCで利用するには、プロジェクトZIPをダウンロードして完全に展開し、そのPCで起動してください。

Python 3.10以上をインストールしたうえで、Windowsは `start.bat`、macOSは `start.command` を開きます。起動ファイルを直接開けない場合は、展開したフォルダ内のターミナルで `python launch.py`（macOSは `python3 launch.py`）を実行してください。必要な依存パッケージを初回だけインストールし、起動を確認してブラウザを自動で開きます。起動したターミナルは開いたままにし、終了時はCtrl+Cを押します。

旧版を使用中の場合は、そのターミナルでCtrl+Cを押して停止し、更新版ZIPを別フォルダへ展開してから起動してください。旧版が8000番ポートに残っている場合、起動スクリプトは停止を案内します。

### 手動セットアップ

必要環境：Python 3.10以上。UIを開発・再ビルドする場合はNode.js 20.19以上（推奨22 LTSまたは24）とnpm。配布ZIPにはビルド済みUIを含めるため、利用だけならNode.jsは不要です。

ZIPを展開し、`flight-simulator` フォルダ内で実行します。

```sh
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell は上の行の代わりに:
# .venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
python run.py
```

ブラウザで **http://127.0.0.1:8000** を開いてください。終了はターミナルで Ctrl+C。初回のパッケージインストールにネット接続が必要です。インストールとビルド後のアプリは外部CDN・外部API・外部フォントに依存せず動作します。

ビルド済みUIがない場合・UIを変更した場合：

```sh
cd frontend
npm ci
npm run build
cd ..
python run.py
```

開発時はターミナルを2つ使います。

```sh
# プロジェクト直下
python -m uvicorn aeroflight.api:app --reload --port 8000
# 別ターミナル、frontend内
npm run dev
```

開発UIは http://localhost:5173 。`/api` はViteから8000番へ転送されます。APIドキュメントは http://127.0.0.1:8000/docs 。ローカル専用で、認証や本番公開向けの実行制限は実装していません。

## 使い方

1. プリセットから GL-01（翼幅1,000mmのグライダー）、RC-02（翼幅1,200mmのモーター機）を選びます。プリセットは架空の機体です。
2. 重量、翼幅、翼根翼弦、テーパー比、重心位置、尾翼、初速・高度・投射角・ピッチ角・風などを変更します。スライダーは即時反映、数値入力はEnterまたはフォーカスを外した時に反映します。数値入力の範囲外・空欄は元の値に戻します。
3. 自動計算は350msの待機後に再実行します。オフにした場合は「計算実行」。設定が変わって結果が古い間はグラフを薄くし、保存・CSV出力を無効にします。エラー時も新しい結果と誤認しない表示になります。
4. 軌道上の機体マーカーは再生時刻・ピッチを反映します。グラフの点をクリックすると時刻が連動します。再生・一時停止、0.5〜4倍速、時刻スライダーを使用できます。軌道のx軸と高度軸の縮尺は独立しているため、画面の線の傾きは実際の飛行経路角ではありません。
5. グラフはドラッグで拡大、ツールバーでパン・縮小・PNG保存、ダブルクリックでリセットできます。凡例をクリックして系列を切り替えられます。速度、空気力、姿勢・迎角、ピッチ角速度を別タブに表示します。角度と角速度は別グラフです。
6. 「設計を保存」で設定と結果をブラウザのlocalStorageへ保存します（最大5案）。チェックした設計を軌道・対気速度・ピッチ角・ピッチ角速度に重ねます。保存案は読込・削除でき、ページを再読込しても残ります。初期再読込時はグラフを見やすくするため重ね合わせをオフにします。
7. 「JSON」は設定と現在の有効な結果を出力し、「読み込み」は設定を検証・再計算して復元します。保存していた結果を信頼してそのまま表示することはしません。設定が未計算ならJSONの`result`はnullです。「CSV」は現在の計算結果を全列・SI単位で出力します（角度・角速度はdeg、deg/s）。データ保存は同じブラウザ・同じオリジンのみで、容量不足時はエラーを表示します。
8. 画面下部の「起動・モデル説明」「ソースZIP」からこの説明とプロジェクト一式を取得できます。ZIPにはソース・テスト・ビルド済みUIを含みます。

## 機体形状と翼型編集

画面上部に、入力に即時連動する3D・上面・側面プレビューを表示します。3Dはドラッグまたは矢印キーで回転できます。WebGLや外部描画サービスは不要です。左の設計パネルは独立してスクロールでき、「翼型を編集」ボタンで断面設定へ移動できます。

- 翼幅・翼根翼弦・テーパー比から主翼を生成し、尾翼面積・翼幅・距離から尾翼を生成します。主翼と尾翼は同じ座標・長さ比率で描画します。寸法変更で画面内に収まるよう全体の表示倍率は自動調整します。
- 取付角で断面を回転し、昇降舵は尾翼後縁30%をヒンジとして表示します。尾翼断面は固定の対称翼による模式表示です。
- CGと中立点、MACの位置を重ねます。部品モードは部品位置も表示し、同じ重量・配置から重心を求めます。
- 胴体とプロペラは位置関係のための模式形状で、これらの見た目から抗力・推力を解析しません。胴体抗力は既存CdA入力、推力は既存推力曲線を使います。重量だけを変えても寸法は自動で変わりません。
- 断面はNACA 0012・2412・4412・2415のプリセットと、最大キャンバー0〜6%、位置10〜80%、厚み4〜24%のスライダーで編集できます。寸法比を保持し、キャンバー線や同じ厚みの対称翼を重ねて比較できます。
- 「DAT」で翼型座標を出力できます（無次元 x/c, y/c、閉じた後縁、上面後縁→前縁→下面後縁）。STLや機体全体のCADではありません。参照の [Foil.tools Kulfan Canvas](https://foil.tools/kulfan-canvas) はCSTの編集・解析機能を備えますが、本アプリの今回の実装はNACA 4桁式です。

NACAモードのキャンバーとその位置は、零揚力角と四分の一翼弦まわりのCmを変え、実際の飛行計算に反映されます。翼厚は断面と3Dメッシュを変えますが、**翼厚に応じた粘性抗力、失速特性、重量・慣性の自動変更は行いません**。CD₀・CLmax・重量・Iyyは引き続き指定値です。対称翼ではキャンバー位置を変えても形状や空力に影響しません。

古いJSONに新しい翼型設定がない場合は手入力モードへ復元し、以前の零揚力角とCm₀を維持します。このモードの断面は翼型未指定の薄板による模式表示で、DAT出力は無効です。新プリセットはNACA 2412を使用するため、旧プリセットと数値が変わります。

## 計算モデル

### 座標・単位

状態は `[x, h, u, w, theta, q]`。地上座標はxが水平前方、hが上向き、機体座標はuが機首前方、wが下向き、ピッチ角theta・角速度qは機首上げが正です。**u, w は対地速度の機体座標成分**で統一します。

```
dx/dt = u cos(theta) + w sin(theta)
dh/dt = u sin(theta) - w cos(theta)
du/dt = X/m - g sin(theta) - q w
dw/dt = Z/m + g cos(theta) + q u
dtheta/dt = q
dq/dt = M/Iyy
```

風速は一定の地上水平風で、追い風を正とします。空気力の計算時に風速を機体座標に変換してu,wから1回だけ差し引きます。位置の更新に風を再加算しません。初速は対地速度、投射角は対地経路角です。機首方向は投射方向と独立です。

内部の力・長さ・質量・状態角度は N / m / kg / rad。設定APIの取付角・初期角等はUIに合わせてdegで受け取り、使用時にradへ変換します。`cg_mac`は百分率ではなく比率（0.30 = 30%）。出力角度はdegです。

### 主翼・尾翼・抗力

主翼は前縁位置が揃った無後退の長方形／テーパー翼です。
本近似の適用条件として主翼ARは2以上に制限します。低AR翼は有限翼・吹き下ろし近似の対象外です。ARが20を超える場合は構造変形を無視する旨を警告します。

```
S = b c_root (1 + taper) / 2
MAC = (2/3) c_root (1 + taper + taper²)/(1 + taper)
AR = b²/S
a = 2π / (1 + 2/(e AR))
CL = clip[a (alpha_eff - alpha_zero), -CLmax, CLmax]
CD = CD0 + CL²/(π e AR) + 大迎角の抵抗補正
L = (rho V_local² / 2) S CL
D = (rho V_local² / 2) S CD
```

有限翼の揚力傾斜と誘導抗力を含みます。`alpha_eff`には取付角を加えます。CL上限以降の抵抗補正は `1.5 sin²(excess)` で連続に接続します。これは数値積分と終了イベントのための限定的な延長であり、失速後の精密モデルではありません。空力係数手入力モードでは零揚力角・Cm₀をユーザーが指定します。NACAモードでは以下のキャンバー線解析で求めます。

尾翼は独自の面積・AR・効率係数・取付角を使用します。吹き下ろしを `epsilon = 2 CL_w / (π AR_w)` と近似し、尾翼迎角から差し引きます。昇降舵の効果は `0.55 × elevator`（後縁下げ正）。固定の尾翼CD₀=0.015、尾翼CLmax=1.0。各空力中心の回転速度（ピッチによる局所u,w）も含み、尾翼によるピッチ減衰を生みます。

胴体抵抗は `0.5 rho V² × body_cda`。主翼・尾翼の揚力・抗力をそれぞれの局所流れ方向から機体座標へ変換します。主翼・尾翼の空力中心は設計上z=0とします。部品モードでCGがz方向に移動した場合、その高さによるモーメントと局所回転速度も反映します。胴体抵抗は重心位置に作用すると仮定します。

空気密度は直接指定。気温はSutherland則による粘性係数とRe数の計算に使います。**Phase 1の係数にはRe依存性を含めません**。Reの警告は行いますが、温度だけを変えても同じ密度なら軌道は変わりません。

### NACAキャンバー線の薄翼理論

キャンバー m、最大位置 p を指定し、x/c < p では `yc/c = m/p² (2p x/c - (x/c)²)`、後方では `m/(1-p)² (1-2p+2p x/c-(x/c)²)` を使用します。厚みは標準的なNACA 4桁式の多項式を使用し、後縁を閉じる係数 -0.1036 とします。上下表面はキャンバー線の法線方向へ厚みを与えます。

`x/c = (1-cos θ)/2`、キャンバー線の傾斜をz′とすると、`alpha_zero = (1/π) ∫z′(1-cos θ)dθ`、`Cm_c/4 = (1/2) ∫z′(cos 2θ - cos θ)dθ`。区分の境界で分けた厳密な原始関数から計算します。NACA 2412の場合は零揚力角 -2.07724°、Cm -0.0531195。これらは粘性を無視した理論値です。揚力傾斜は既存の有限翼補正を適用します。Cmはこの2D理論値を主翼のS・MACで寸法化する近似です。

厚みはこの理論に含まれません。キャンバー4%超や厚み18%超では追加警告を出します。Re依存、剥離、表面粗さ、プロペラ後流、CSTの解析は追加していません。キャンバーからの連動が増えたことは、実機予測精度を保証しません。

### 重心と慣性

部品位置xは主翼前縁から後方、zは下方。部品から以下を計算します。

```
m = Σm_i
CGx = Σm_i x_i / m, CGz = Σm_i z_i / m
Iyy = Σ[Iyy_i + m_i ((x_i-CGx)² + (z_i-CGz)²)]
```

主翼ACは0.25 MAC、尾翼ACは主翼ACから入力した尾翼距離だけ後方。各力の重心まわりの腕と主翼Cm₀からモーメントを求めます。部品固有Iyyを0にもできますが、合成Iyyが小さすぎる入力は拒否します。手入力モードでは質量・重心・Iyyを独立に指定します。部品質量やバッテリーを重複して加算しません。

### 推進

グライダーとモーター機は同じエンジンを使用し、グライダーでは推力を0にします。モーター機は固定全開推力、または全開推力と速度の折れ線を使い、スロットルを乗じます。曲線は線形補間し、範囲外では端点に固定して警告します。推力軸はCGに対する下方距離と上向き角を指定可能。`M_thrust = thrust_z × T cos(thrust_angle)`。モーター・プロペラ回転数や電池容量からの推力推定はPhase 2以降です。

### 積分・終了

SciPy `solve_ivp` の適応刻みRK45。最大積分刻み・相対／絶対許容誤差と、グラフ出力間隔は独立です。既定は最大刻み0.02秒、rtol=1e-7、atol=1e-9、出力0.05秒。密出力でサンプリングし、接地イベントの時刻を最終行に必ず含めます。

終了条件は接地、指定時間、迎角（主翼または尾翼）60°以上、ピッチ角速度180°/s以上、対気速度0.5m/s以下または80m/s以上です。有効範囲を超えた結果は着地予測と区別します。積分失敗や非有限値はAPIエラーにし、不正な新結果を表示しません。接地時刻・距離・対地速度を記録します。

### 安定性の参考値

静安定余裕は、主翼と尾翼の揚力傾斜・尾翼効率・面積・吹き下ろし勾配を使用した線形近似です。

```
d_epsilon = 2 a_w / (π AR_w)
K_tail = eta S_tail a_tail (1 - d_epsilon)
x_neutral = x_ac_w + tail_arm K_tail / (S_w a_w + K_tail)
static_margin = (x_neutral - CGx) / MAC
```

これは小迎角・固定操舵・準定常の参考値です。**トリム解、動安定性の固有値、実際の飛行可否は評価しません**。正の余裕でも飛行を保証しません。参考失速速度は `sqrt(2mg/(rho S CLmax))` で水平・主翼支持を仮定した目安です。飛行中の失速判定の万能閾値ではありません。

## 適用範囲と今後

- 全結果の出典は **工学的近似**。計算結果にはモデルバージョン、入力、積分条件、出典を保存します。
- 低Re数（100,000未満）、12°超の翼迎角、CLmax付近、60°/s超の強いピッチ運動で警告します。高Reで精度を保証するものではありません。
- 失速・剥離・スピン、地面効果、突風、横滑り、ロール・ヨー、空力弾性、材料強度、プロペラ後流、バッテリー消耗を再現しません。
- NACA 4桁式の形状編集と3D形状プレビューを実装済みです。CST/Kulfan係数の編集、XFOIL α/Re/CL/CD/Cm補間、トリム・動安定解析、感度分析は未実装です。STL/CAD連携、実測校正、6DoFも今後の対象です。
- `aero.py`（空力）と`simulation.py`（状態・積分）を分離しています。空力を差し替え、状態・運動学を拡張できる構造です。エンジンはFastAPI・UIをインポートしません。

v0.2の検証結果はPython物理・API 44件、形状のJavaScript単体試験5件、ブラウザ試験9件が通過。キャンバー変更が実際の係数・軌道を変えること、厚みだけでは空力を変えないこと、形状の即時更新、CG移動、3D回転、昇降舵、DAT出力、旧JSON互換を確認しています。
